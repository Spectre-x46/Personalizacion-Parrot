# Programas que componen el setup (los instala install.sh automaticamente)
# Regla Parrot: solo 'apt install' puntual, NUNCA 'apt upgrade'.

## Grupo facil (apt install)
git curl wget unzip fontconfig xdotool
zsh                       # shell
zsh-autosuggestions       # sugerencias en la terminal
zsh-syntax-highlighting   # colores en la terminal
feh                       # wallpaper
rofi                      # menu de apps
bat                       # 'cat' con colores (alias cat=bat)
lsd                       # 'ls' bonito (alias ls=lsd)

## Grupo "version nueva" (no van por apt normal)

sxhkd  0.6.3    -> compilar (github.com/baskerville/sxhkd)
picom  v12      -> compilar (github.com/yshui/picom)   [DECIDIDO: Opcion A]
kitty  0.44+    -> instalador oficial (sw.kovidgoyal.net/kitty)
neovim 0.11.5   -> release oficial (github.com/neovim/neovim)

## Extras (clonados por el script)

NvChad (v2.5)            -> ya viene dentro de common/nvim; plugins via Lazy
